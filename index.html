What is IslandSMP?

IslandSMP is a fun and friendly Public Minecraft Survival Server.

How do I join IslandSMP?

If you want to join IslandSMP, on Java click "Add Server", then for the IP type IslandSMP.apexmc.co.

For Bedrock, click "Add Server", then type for the IP IslandSMP.apexmc.co and for the port type 25756.

Spawner Drops

Pig Spawner

The Pig Spawner has a 70% chance to generate Pork Chops to eat or sell.

Bat Spawner

The Bat Spawner has an 85% chance to generate Spider Eyes to sell.

Spider Spawner

The Spider Spawner has a 58% chance to generate Spider Eyes and an 88% chance to generate String to craft or sell.

Zombie Spawner

The Zombie Spawner has a 66% chance to generate Rotten Flesh, a 1% chance for Iron Ingots, a 24% chance for Carrots, a 6% chance for Potatoes, and a 45% chance for Golden Ingots. There is also a 0.1% chance to drop a Zombie Head.

Skeleton Spawner

The Skeleton Spawner has a 79% chance to generate a Bone, a 72% chance to generate an Arrow, an 18% chance to generate a Bow, and a 0.1% chance to generate a Skeleton Skull.

Enderman Spawner

The Enderman Spawner has a 65% chance to generate an Ender Pearl and an 80% chance to generate End Stone.
